# Enneagram Test

A full-stack, web-based personality assessment built for the OANDA Enneagram Project. The tool administers a 180-item psychometric survey and uses statistical modeling to segment users based on their needs, expectations, and goals.

🔗 Live site: [oandaenneagram.com](https://www.oandaenneagram.com)

## What it does

- Serves an 180-item personality assessment to users through a web interface
- Scores responses and validates the instrument using reliability analysis (Cronbach's Alpha)
- Applies Principal Component Analysis (PCA) and cluster analysis to segment users into personality profiles
- Translates statistical output into user-facing results and product/marketing insights

## Tech stack

- **Frontend/Backend:** JavaScript, Google Apps Script
- **Hosting/Deployment:** Vercel
- **Statistical analysis:** R (PCA, cluster analysis, reliability analysis)

## Background

Built as part of the OANDA Enneagram Project (Sep 2025 – Jun 2026), where I served as Co-Founder & Research Lead. I designed the assessment instrument, ran the psychometric validation, and led the technical development and deployment of the platform end-to-end — from survey design to statistical modeling to shipped product.
